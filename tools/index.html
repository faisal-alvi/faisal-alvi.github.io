Built for my own workflow

Tools I Built

I log a lot of hours and juggle a lot of tickets, so I built small tools to stop doing that by hand. They run entirely in your browser, with no server and no sign-up. Use them if they help.

Teamwork Time Logger

Log and review hours on Teamwork without opening Teamwork. A week-at-a-glance view, one-click quick tasks, and ticket estimates that show hours logged against a t-shirt size (XS to XXL). Everything is a single HTML file, and your API key never leaves your browser except to talk to Teamwork.

Open the Time Logger

How to use it

  1. Get your API key. In Teamwork, open your profile, then Edit my details, then the API & Mobile tab, and copy your token.
  2. First run. Enter your Teamwork site (for example yourcompany.teamwork.com) and the key. They are stored in your browser's localStorage only.
  3. Log time. Pick a project and task, tap a quick-time button, set the date, and save. Edit, duplicate or delete any entry inline.
  4. Save your repeat tasks as Quick Tasks, then log them with one click.
  5. Paste a ticket URL or ID into Ticket Lookup to see every entry logged against it, then use the Month Report to copy a project breakdown.

Personal Schedule

A day planner where tasks have a length and flow around fixed events like prayer times and meals. Drag to move, drag the bottom edge to resize, undo and redo freely. My real copy is password-locked and encrypted in my browser, so the live version is a demo with sample data.

Try the live demo

How to use it

  1. Open the demo. It runs in memory with sample tasks, so nothing is saved and nothing can break.
  2. Add a task with the Add task box. Give it a duration and it lands in the next free slot.
  3. Move and resize. Drag the grip to reorder, drag the bottom edge to change length. Tasks reflow around your daily events.
  4. Set your day. Tap the working hours button to change start and end for just that day, and use Daily event to block time you never want scheduled over.
  5. Mistakes happen. Undo and redo are in the header.

Dev Dashboard

One screen for my GitHub pull requests and review queue, built as a static page. Tokens stay in localStorage and calls go from your browser straight to the API.

Open the Dev Dashboard

How to use it

  1. Create a GitHub personal access token that can read your pull requests.
  2. Paste it into Settings. It is kept in your browser only.
  3. My PRs shows what you have open, Review Queue shows what is waiting on you.
